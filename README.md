## Распознавание облачности на спутниковых снимках. Кейс «Спутникс» для Sk Challenge 2026

Мой ИИ-Алгоритм на базе сверточной нейросети **U-Net** для автоматической сегментации облачного покрова, расчета процента облачности и фильтрации снимков ДЗЗ (Дистанционного зондирования Земли).

## Мое решение: 
По данным исследований ДЗЗ, до 67% спутниковых снимков содержат избыточную облачность (Ссылка на исследование в презентации). Мой алгоритм решает задачу в автоматическом режиме. Вот что он делает:
1. Выполняет попиксельную сегментацию облаков на снимке.
2. Вычисляет точный процент облачного покрытия.
3. Отсеивает и удаляет кадры с облачностью **> 75%**, создавая консольный и визуальный отчет для оператора с именем файла и долей облачности.

## Технологии, которые я использовал:
* **Язык Программирования:** Python 3
* **Нейросеть:** U-Net с предобученным энкодером **ResNet34** (`segmentation_models_pytorch`)
* **Библиотеки:** `torch`, `torchvision`, `opencv-python (cv2)`, `numpy`, `matplotlib` 
* **Параметры обучения:** разрешение `256×256`, функция потерь `BCEWithLogitsLoss`, оптимизатор `Adam (lr=1e-4)`, автогенерация псевдомасок по порогу яркости в цветовом пространстве HSV.

## Как запустить мой алгоритм:

1. Клонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone https://github.com
   cd sputnix-cloud-segmentation-4-sk-challenge
   ```

2. Установите зависимости:
   ```bash
   pip install torch torchvision segmentation-models-pytorch opencv-python numpy matplotlib
   ```

3. Подготовьте папки с данными в корне проекта:
   * `images/` - снимки для обучения модели;
   * `test_images/` - снимки для тестовой фильтрации. Результаты разметки сохранятся в `visual_results/`.

4. Запустите ноутбук `Code.ipynb`.

## Как мое решение поможет «Спутникс»:

| Показатель | Ручная проверка | Мой алгоритм U-Net | Выгода для «Спутникс» |
| :--- | :--- | :--- | :--- |
| Проверка 1 000 снимков | **~3–4 часа** работы оператора | **15–30 секунд** на GPU или до 3 минут на CPU | Ускорение в **80–300 раз** |
| Объем хранения | До 3 ТБ/мес | Удаляется **30–50%** кадров (> 75% облаков) | Экономия **до 1,5 ТБ/мес и 18 ТБ/год** соответственно |
| Точность отбора | оценка «на глаз» | Единый математический порог **75,0%** | **0% ошибок** человеческого фактора |
| Рост до 99 спутников | Нужен целый штат дешифровщиков | Автоматическая потоковая обработка | Готовность к росту флота **в 20 раз** |
